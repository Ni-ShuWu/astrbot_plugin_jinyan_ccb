# 禁言嘲讽插件

AstrBot 插件，当群内有用户被禁言时，自动发送一条嘲讽消息。

## 功能

- 当群成员被管理员禁言时，机器人自动在群里发送一句随机嘲讽语录
- 内置 **300 条以上** 嘲讽文案，每次随机抽取，拒绝重复感
- 文案分为抽象派、元游戏、短句快打三类，可分别开关
- 支持在 AstrBot 插件配置界面填写**自定义嘲讽文案**，可选「仅内置 / 仅自定义 / 混合」三种来源
- 支持 AstrBot 插件配置界面**配置黑名单群号**，无需重启即可生效
- 支持通过指令快捷管理黑名单
- 仅对 `ban` 类型、时长 > 0、非全员禁言的事件触发

## 安装&使用方法

### 安装

- 在 AstrBot 插件市场搜索「禁言嘲讽」并安装
- 在 GitHub 下载最新的插件源码 zip 包，在 AstrBot 插件管理界面上传安装

### 使用

- 在 AstrBot 插件配置界面启用插件（默认是启用的）
- 在群里禁言某个成员，机器人会自动发送一条嘲讽消息
- 如果不希望在某些群里发送嘲讽消息，可在 AstrBot 插件配置界面添加黑名单群号，或使用指令管理黑名单

## 配置说明

插件的配置项定义在 `_conf_schema.json`，可在 AstrBot 后台「插件配置」中直接编辑：

| 配置项 | 类型 | 说明 |
| --- | --- | --- |
| `blacklist_groups` | list[str] | 不发送嘲讽的群号列表，每行一个群号 |
| `enable_at_all` | bool | 是否在嘲讽消息中 @ 被禁言用户 |
| `enable_abstract` | bool | 是否启用抽象派文案 |
| `enable_meta` | bool | 是否启用元游戏文案 |
| `enable_short` | bool | 是否启用短句快打文案（也包含旧版文案） |
| `custom_mode` | string | 嘲讽文案来源：`builtin` 仅内置 / `custom` 仅自定义 / `mixed` 混合 |
| `custom_messages` | text | 自定义嘲讽文案，每行一条，仅当 `custom_mode` 不为 `builtin` 时生效 |

黑名单的修改会立即写入 AstrBot 的插件配置文件并生效。

## 指令

虽然可以通过配置界面管理黑名单，插件也提供了指令版本，方便在群里操作：

```
/禁言嘲讽黑名单 add 123456     添加群 123456 到黑名单
/禁言嘲讽黑名单 remove 123456  从黑名单移除群 123456
/禁言嘲讽黑名单 list           查看当前黑名单
```

通过指令添加/移除的黑名单也会同步写入 AstrBot 插件配置。

## 效果示例

- 哈哈哈哈，克菜 被禁言了，经典！
- 克菜 的嘴被术无锁住了，钥匙呢？扔了！
- 克菜：我就说了一句！ 术无：一句也不行
- ……（共 200 条随机文案）

## 自定义文案

有两种方式自定义嘲讽文案。

### 方式一：插件配置界面（推荐）

在 AstrBot 后台「插件配置」中：

- `custom_mode`：选择文案来源
    - `builtin`：仅使用内置文案（默认，保持原有行为）
    - `custom`：仅使用自定义文案
    - `mixed`：内置文案与自定义文案一起随机抽取
- `custom_messages`：填写自定义文案，**每行一条**

支持以下占位符：

- `{user}`：被禁言用户的昵称
- `{admin}`：执行禁言的管理员昵称（获取失败时回退为 QQ 号或「管理员」）
- `{duration}`：禁言时长（自动格式化为 秒/分钟/小时/天）
- `{model}`：从 `model.py` 的 `MODEL_TEXTS` 列表中随机抽取的一段文本

例如（设术无为 `{admin}`，克莱为 `{user}`）：

```
{user}被{admin}禁言了{duration}唉，真是杂鱼❤️~~~
```

将发送为：`克莱被术无禁言了1小时唉，真是杂鱼❤️~~~`

### 方式二：修改源码

嘲讽文案位于 `messages.py`，分组列表为 `ABSTRACT_MESSAGES`、`META_MESSAGES` 和 `SHORT_MESSAGES`；原有文案也会自动按内容归入这三类。可直接修改 `model.py` 中的 `MODEL_TEXTS` 来自定义随机文本。

## 注意事项

- 仅支持 OneBot 协议平台（如 NapCatQQ、LLOneBot 等）
- 解禁事件和全员禁言不会触发嘲讽
- 兼容 AstrBot 插件配置系统，配置改动会自动保存到 `config.json`
- 该插件仅用于娱乐，禁止用于恶意骚扰或攻击他人
- 这个插件是作者恶趣味的产物，若你觉得不适合你的bot，请不要安装
- 该插件的文案可能包含一些不适合未成年人或敏感人群的内容，请谨慎使用
